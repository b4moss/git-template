# 合同会社 知的・自転車　Go開発テンプレート

ライセンス：MIT LICSENSE

## 開発

アプリ本体は [`dev/`](dev/) です。ローカルの Go を使い、バージョンは `dev/go.mod` の `go` / `toolchain` で固定します。

```bash
cd dev
go mod tidy
go run .
```

またはルートから:

```bash
make run
```
